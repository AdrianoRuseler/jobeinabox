API Quick Reference

Method Endpoint Description
GET /jobe/index.php/restapi/languages List supported languages and versions
POST /jobe/index.php/runs Submit a job for execution
PUT /jobe/index.php/files/{id} Upload a support file
GET /jobe/index.php/files/{id} Check a file exists (HEAD also supported)

Example — Submit a Python3 Job

// POST /jobe/index.php/runs { "run_spec": { "language_id": "python3", "sourcecode": "print('Hello, Jobe!')", "sourcefilename": "hello.py" } } // Response (outcome 15 = success) { "run_id": null, "outcome": 15, "stdout": "Hello, Jobe!\n", "stderr": "", "cmpinfo": "" }
